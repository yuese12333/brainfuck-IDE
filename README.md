## 🎯 项目亮点

- 🚀 **高性能执行** - 批量执行模式达到 100K+ IPS
- 🐛 **专业调试** - 指令级断点 + 单步执行 + 括号匹配
- 🎨 **现代化UI** - VS Code 风格深色主题 + 响应式设计
- ⚙️ **高度可定制** - 快捷键、速度档位完全可配置
- 🔍 **智能检查** - 静态分析（括号、字符、越界）
- 📦 **开箱即用** - 无需配置，内置示例和完整文档

- ✅ **代码编辑器** - 语法高亮、行号显示、注释支持（# 符号）、智能输入

- ✅ **输入输出** - 支持字符/ASCII两种模式，控制字符可视化显示
- ✅ **状态监控** - 实时显示执行状态、指令计数、IPS、内存指针
- ✅ **性能分析器** - 点击执行次数查看指令统计，支持颜色编码和数据持久化
- ✅ **指令按钮** - 8个快捷按钮，可自定义键盘快捷键
- ✅ **静态检查** - 括号匹配、无效字符、指针越界检测
- ✅ **括号匹配** - 光标旁括号自动高亮配对，支持嵌套
- ✅ **完成状态** - 程序执行完成后显示"完成"状态，区分就绪状态

## 📖 Brainfuck 指令说明

| 指令 | 说明 |
|------|------|
| `>` | 指针右移一位 |
| `<` | 指针左移一位 |
| `+` | 当前单元值加1 |
| `-` | 当前单元值减1 |
| `.` | 输出当前单元的字符 |
| `,` | 读取一个字符到当前单元 |
| `[` | 如果当前单元为0,跳转到匹配的] |
| `]` | 如果当前单元不为0,跳回到匹配的[ |

## 🎯 使用指南

### 基本操作
1. **编写代码** - 在代码编辑器中输入 Brainfuck 代码，支持 # 注释（整行或行内）
2. **快捷输入** - 使用底部8个指令按钮或配置的快捷键（默认1-8）快速插入指令
3. **静态检查** - 点击"🔍 检查"按钮验证代码：括号匹配、字符有效性、指针越界
4. **设置断点** - 点击要设置断点的指令，确认后设置/取消断点（红色高亮标记）
5. **运行程序** - 点击"▶️ 运行"按钮开始执行，可选择四档速度（最快/快/中/慢）
6. **断点调试** - 程序遇到断点会自动暂停，点击"⏭️ 继续"恢复执行
7. **单步执行** - 点击"⏯️ 单步"逐条执行指令，观察内存和输出变化
8. **查看内存** - 自动跟随指针位置，或手动翻页浏览30000个内存单元
9. **调整速度** - 使用四个速度按钮控制执行快慢：
   - 最快：0ms延迟，批量执行，100K+ IPS
   - 快：50ms延迟
   - 中：100ms延迟
   - 慢：200ms延迟
10. **输入输出** - 输入区支持字符/ASCII模式，输出区支持字符/ASCII显示（控制字符可视化）
11. **性能分析** - 点击状态栏"执行次数"查看详细指令统计，支持颜色编码和保持统计功能
12. **括号匹配** - 将光标放在 `[` 或 `]` 右侧，自动高亮显示配对括号
13. **自定义设置** - 点击"⚙️ 设置"自定义快捷键（预设：数字/Home Row）和速度档位

### 快捷键（可自定义）
默认配置：
- `1` - 插入 `>` （指针右移）
- `2` - 插入 `<` （指针左移）
- `3` - 插入 `+` （值加1）
- `4` - 插入 `-` （值减1）
- `5` - 插入 `.` （输出）
- `6` - 插入 `,` （输入）
- `7` - 插入 `[` （循环开始）
- `8` - 插入 `]` （循环结束）

可在设置中切换到 Home Row 预设（a/s/d/f/j/k/l/;）或自定义任意键。

### 代码示例

#### Hello World
```brainfuck
# 经典的 Hello World 程序
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
```

#### 输出字母A（ASCII 65）
```brainfuck
# 将内存单元设置为65并输出
+++++[>+++++++++++++<-]>.
```

#### 简单加法（输入两个数字，输出和）
```brainfuck
# 读取两个数字相加
,>,<[>+<-]>.
```
## 🌟 特色功能

### 性能优化
- **批量执行** - 最快模式下每次UI更新执行1000条指令
- **IPS监控** - 实时显示指令执行速度（支持K/M单位格式化）
- **性能分析器** - 可视化指令执行统计，支持颜色编码和数据持久化
- **高性能渲染** - 优化的语法高亮和内存显示

### 智能编辑
- **注释支持** - 使用 # 符号添加整行或行内注释
- **智能输入** - 注释区域自由输入，代码区域受快捷键控制
- **焦点隔离** - 输入框和设置界面不受编辑器快捷键影响
- **括号高亮** - 光标旁的括号自动显示配对位置（金色高亮 + 脉冲动画）

### 静态分析
- **括号匹配** - 检测未闭合或多余的方括号
- **字符验证** - 识别无效字符，提示正确的指令集
- **指针越界** - 模拟执行检测指针是否超出内存范围（0-29999）
- **错误定位** - 精确显示错误所在行号和位置

### 调试增强
- **指令级断点** - 基于指令位置而非行号，精确控制
- **选择设置** - 点击指令即可切换断点（带确认对话框）
- **状态追踪** - 区分就绪/运行中/暂停/完成四种状态
- **视觉反馈** - 当前指令金色高亮，断点红色背景

### 用户体验
- **自动跟随** - 内存显示自动跳转到指针所在页
- **设置持久化** - 快捷键和速度配置自动保存到localStorage
- **错误提示** - 静态检查和运行时错误都有详细提示
- **控制字符** - 输出中的控制字符显示为可读标记（如 ⟨LF⟩、⟨NUL⟩）
